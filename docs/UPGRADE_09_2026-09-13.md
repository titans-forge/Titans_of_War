# Civil War Upgrade 09 — Campaign continuity (0.11.0)

The campaign now exposes save status in the main view, battle entry and after-action report. A failed save offers Retry save and Export campaign save directly. An unreadable protected original offers export only, preserving the existing recovery boundary. Demo saves identify themselves separately.

The journal now retains an expandable field report for each recorded battle: mission assessment, evidence, losses when available, and commanded/delegated provenance. Older reports use the existing legacy assessment fallback. No new archive fields are needed.

Battle entry explains the actual save boundary: active battlefield progress is not saved; finish and return consequences before closing or reloading. This release does not add mid-battle resume.
