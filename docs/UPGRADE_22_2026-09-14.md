# Upgrade 22 — find objectives, landmarks and exits

Release: 0.24.0. Campaign save version 21 and battle rules 17 remain unchanged.

## Player-facing changes

“Find on field” brings the existing mission targets, command sectors, historical landmarks and actual Confederate exit destinations into one compact camera menu. Sector status strips are now keyboard-accessible View buttons. Henry Hill's defense objective and Petersburg's selected sortie targets lead the relevant lists.

View pauses play, frames the location with nearby ground, and draws a named gold outline. It preserves formation selection, orders and pending move previews. Overview removes the marker and restores the full field; focusing an active formation clears the marker. Existing landmark and sortie-checklist View actions use the same framing. Markers remain visible while resizing. Resuming and then resizing preserves the running speed.

The menu identifies the coordinates as a playable board. It uses actual engine destinations, including Winchester's lower-left corridor and the separate Gettysburg rear exits. It does not calculate a safe route or add geographic bearings. Unsupported legacy boards expose no invented targets. Existing reserve/support guidance and command receipts continue to apply.

On narrow screens, zoom controls move into Map & sound so Find on field fits on the main toolbar. The large paused-field prompt is suppressed while a location is marked, keeping the exit visible; speed controls remain in the header. Escape closes the location menu and restores focus to its summary.
