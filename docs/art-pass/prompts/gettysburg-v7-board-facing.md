# Gettysburg v7: board-facing march source generation

October 1, 2026. Built-in imagegen; underlying model identifier not reported. Six-source S/N pilot remains opt-in; model-assisted review is not human or historical certification. Native RGBA outputs and failed attempts are preserved without raster editing. Each complete four-cell march and action sheet is measured and reviewed before registration.

The engine probe changed priority: opening Union infantry face S and Confederate infantry face N. Authored simulated maneuvers suggest these views matter more than extending B to E/SE. Those probes are design evidence, not player-frequency or balance validation.
